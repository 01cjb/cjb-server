# CJB 업무 시스템 (/work)

사내 직원 전용 화면. 쇼핑몰 회원 로그인과 별개로 **이름 + 연락처 + 6자리 PIN**으로 들어갑니다.

## 처음 설정 (1회)
1. 이 변경이 배포되면 DB에 `work_*` 테이블이 자동 생성됩니다 (migration `20261110000000_work.sql`).
2. 쇼핑몰 최고관리자 계정으로 로그인 → `/work/setup` 에서 대표 계정(이름·연락처·PIN) 생성.
3. `/work/login` 으로 대표 로그인 → **사용자·권한** 에서 직원 등록, PIN 발급, 메뉴 체크.

## 로그인·보안
- PIN은 대표가 발급(자동 발급 시 화면에 1회만 표시). DB에는 scrypt 해시만 저장.
- 연락처 미등록 직원은 이름 + PIN으로 입장. 연락처가 등록된 직원은 연락처까지 입력해야 함.
- PIN 5회 오류 → 15분 잠금 (대표가 즉시 해제 가능). 모든 시도는 `work_login_logs` 에 기록.
- 세션 12시간, httpOnly 쿠키. PIN 재발급·계정 중지 시 기존 로그인 즉시 종료.
- "아이디 저장"은 이 기기 브라우저에 이름·연락처만 저장 (PIN 제외).

## 메뉴 / 권한
- 메뉴 목록: `lib/work/menus.ts` (팀: 경영지원 · 영업 · 디자인·마케팅 · 물류 · 개발).
- 권한은 **개인별 메뉴 체크**(`work_user_menus`). 대표(`is_owner`)는 전체 + 사용자 관리.
- 화면 상태: 데이터 연결됨 = 세무(계산서)·매출·고객사·스토어·재고·주문·배송·송장·프론트·백엔드 /
  준비중 = 회계·인사·노무·매입·원장(이카운트 연동 예정), 디자인·마케팅 관리.
- 메뉴 추가: `menus.ts` 에 항목 추가 → `components/work/views.tsx` 에 화면 추가.
