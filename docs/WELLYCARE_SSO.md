# 웰리케어 ↔ 뷰티웰 자동 로그인 연동 안내 (양방향)

한쪽에 로그인한 회원이 다른 쪽으로 넘어갈 때 **다시 로그인하지 않게** 하는 연동입니다.
**양쪽이 똑같은 방식**을 씁니다. A는 웰리케어 → 뷰티웰(뷰티웰 쪽 준비 완료), B는 뷰티웰 → 웰리케어(웰리케어 쪽에 같은 API가 필요)입니다.
웰리케어 개발팀에 이 문서를 전달해 주세요.

# A. 웰리케어 → 뷰티웰

## 한눈에 보기

1. 회원이 웰리케어 앱에서 「뷰티웰」 버튼을 누른다.
2. **웰리케어 서버**가 뷰티웰에 "이 연락처 회원의 입장 주소를 주세요"라고 요청한다. (비밀키 사용)
3. 뷰티웰이 **2분 동안 한 번만 쓸 수 있는 입장 주소**를 돌려준다.
4. 앱이 그 주소를 연다(웹뷰 또는 브라우저) → 로그인된 상태로 뷰티웰 홈이 열린다.

- 회원은 **연락처(휴대폰 번호)** 로 찾습니다. 웰리케어에 등록된 번호와 뷰티웰 회원정보의 번호가 같아야 합니다.
- 연락처·이름 같은 개인정보는 주소(URL)에 넣지 않습니다. 주소에는 뜻 없는 1회용 값만 들어갑니다.
- 비밀키는 **서버에만** 두세요. 앱(안드로이드/iOS) 코드나 웹 화면에 넣으면 안 됩니다.

## 1) 입장 주소 받기 (웰리케어 서버 → 뷰티웰)

```
POST https://cjb-server.vercel.app/api/partner/wellycare/ticket
Authorization: Bearer <비밀키>
Content-Type: application/json

{ "phone": "01012345678" }
```

`phone` 은 하이픈이 있어도 없어도 됩니다.

### 응답

뷰티웰 회원인 경우

```json
{ "member": true, "url": "https://cjb-server.vercel.app/api/partner/wellycare/enter?ticket=…", "expires_in": 120 }
```

뷰티웰 회원이 아닌 경우 (또는 같은 번호의 회원이 여러 명인 경우)

```json
{ "member": false, "reason": "not_member", "url": "https://cjb-server.vercel.app/login" }
```

`reason` 은 `not_member`(뷰티웰에 그 번호의 회원이 없음) 또는 `duplicate`(같은 번호 회원이 2명 이상) 입니다.
두 경우 모두 `url` 을 그대로 열면 뷰티웰 로그인 화면이 나옵니다.

### 오류

| 상태 | 뜻 |
|---|---|
| 400 | `phone` 값이 올바르지 않음 |
| 401 | 비밀키가 틀림 |
| 500 | 일시적인 오류 — 잠시 후 다시 요청 |
| 503 | 뷰티웰 쪽에 비밀키가 아직 설정되지 않음 |

## 2) 입장 주소 열기 (앱)

응답으로 받은 `url` 을 **그대로** 웹뷰나 브라우저로 엽니다. 따로 붙일 값은 없습니다.

- 열리면 로그인된 상태로 뷰티웰 홈(`/`)으로 이동합니다.
- 입장 주소는 **발급 후 2분 안에, 한 번만** 쓸 수 있습니다. 버튼을 누를 때마다 새로 받으세요. 미리 받아 두거나 저장해 두면 안 됩니다.
- 시간이 지났거나 이미 쓴 주소를 열면 뷰티웰 로그인 화면이 나옵니다.
- 웹뷰를 쓸 경우 쿠키가 유지되도록 설정해 주세요. (로그인 상태는 쿠키로 유지됩니다)

## 3) 비밀키

- 뷰티웰(씨제이비) 담당자가 만들어서 Vercel 환경변수 `WELLYCARE_SSO_SECRET` 에 넣고, 같은 값을 웰리케어 개발팀에 **안전한 방법으로** 전달합니다. (메신저 단체방·메일 본문에 그대로 붙이지 않기)
- 24자 이상의 무작위 문자열을 쓰세요.
- 값을 넣거나 바꾼 뒤에는 Vercel에서 다시 배포해야 적용됩니다.
- 키가 새어 나간 것 같으면 Vercel에서 값을 바꾸고 웰리케어에 새 값을 전달하면 됩니다. 이전 키는 바로 못 쓰게 됩니다.

## 4) 지금 정해진 동작과 나중에 바꿀 수 있는 것

| 항목 | 지금 동작 |
|---|---|
| 뷰티웰에 없는 회원 | 자동 가입시키지 않음. 로그인 화면으로 안내 |
| 회원 등급 | 바꾸지 않음. 뷰티웰에 있는 등급 그대로 (VIP가는 미용사 인증 회원만) |
| 이용정지·탈퇴 회원 | 자동 로그인하지 않음 |
| 주소 | 임시 주소(`cjb-server.vercel.app`). 정식 도메인이 생기면 주소만 바뀜 |

## 4-1) 전화번호 보관 (제3자 제공 동의 문구용)

- 웰리케어가 보낸 전화번호는 **회원을 찾는 데만 쓰고, 뷰티웰 DB나 로그에 저장하지 않습니다.** 회원이 아닌 번호(`not_member`)도 마찬가지입니다. → 보관 기간: 저장하지 않음(0일)
- 번호는 요청 본문으로만 오가며 주소(URL)에 들어가지 않으므로 접속 기록에도 남지 않습니다.
- 회원인 경우에만 **1회용 입장권 발급 기록**이 남습니다. 내용은 회원 번호(내부 ID)·발급 시각·사용 시각이며, 전화번호와 입장권 원본은 들어 있지 않습니다.
- 한 번호로 `not_member` 가 나오면 **다른 번호(매장 전화 ↔ 대표자 휴대폰)로 한 번 더 호출해도 됩니다.** 횟수 제한은 없지만 회원 1명당 2번 이내로 해 주세요.

## 4-2) 비밀키 교체 절차

옛 키와 새 키를 **잠시 같이 받을 수 있습니다.** 끊김 없이 바꾸는 순서:

1. 뷰티웰이 새 키를 만들어 Vercel 환경변수 `WELLYCARE_SSO_SECRET_NEXT` 에 넣고 재배포 → 이때부터 옛 키·새 키 둘 다 통과
2. 새 키를 웰리케어에 안전하게 전달 → 웰리케어가 새 키로 교체
3. 뷰티웰이 `WELLYCARE_SSO_SECRET` 을 새 키로 바꾸고 `WELLYCARE_SSO_SECRET_NEXT` 를 지운 뒤 재배포 → 옛 키는 이때부터 거절(401)

키가 새어 나간 급한 상황이면 겹치는 기간 없이 바로 바꿉니다: `WELLYCARE_SSO_SECRET` 을 새 키로 바꾸고 재배포(옛 키 즉시 거절) → 웰리케어가 새 키로 바꿀 때까지 자동 로그인만 잠시 멈추고, 회원은 뷰티웰 로그인 화면으로 들어옵니다.

## 5) 연동 확인 순서

1. 뷰티웰 관리자 화면에서 테스트할 회원의 연락처가 웰리케어에 등록된 번호와 같은지 확인
2. 웰리케어 서버에서 1)번 요청 → `member: true` 와 `url` 이 오는지 확인
3. 그 `url` 을 2분 안에 열어서 뷰티웰 홈이 로그인된 상태로 열리는지 확인
4. 같은 `url` 을 한 번 더 열면 로그인 화면이 나오는지 확인 (한 번만 쓸 수 있어야 정상)

# B. 뷰티웰 → 웰리케어 (같은 방식, 방향만 반대)

뷰티웰에 로그인한 회원이 「웰리케어」 버튼을 누르면 웰리케어에도 로그인된 상태로 들어가게 합니다.
이 방향은 **웰리케어 쪽에 A와 똑같은 모양의 API 2개**가 있어야 합니다. 뷰티웰 쪽은 준비되어 있습니다.

## 웰리케어가 만들 것

### B-1) 입장 주소 발급 API (뷰티웰 서버 → 웰리케어)

```
POST <웰리케어가 정한 주소>          예) https://salon.wellycare.kr/api/partner/beautywell/ticket
Authorization: Bearer <비밀키>       ← A와 같은 비밀키
Content-Type: application/json

{ "phone": "01012345678" }
```

응답 (A와 같은 모양)

```json
{ "member": true, "url": "https://salon.wellycare.kr/…1회용 입장 주소…", "expires_in": 120 }
```

```json
{ "member": false, "url": "https://salon.wellycare.kr/" }
```

- `url` 은 반드시 `https` 이고 웰리케어 도메인이어야 합니다. 다른 도메인이면 뷰티웰이 이동시키지 않습니다.
- 회원은 **연락처**로 찾습니다. (고객사명·PIN은 주고받지 않습니다)
- 5초 안에 응답이 없으면 뷰티웰은 자동 로그인 없이 웰리케어 첫 화면으로 보냅니다.

### B-2) 입장 주소 처리 (회원의 브라우저/웹뷰가 엶)

B-1에서 돌려준 `url` 을 열면 그 회원으로 로그인시키고 웰리케어 화면으로 보내 주세요.
A와 같이 **짧은 시간(2분) 안에 한 번만** 쓸 수 있게 해 주세요. 연락처 같은 개인정보는 주소에 넣지 말고 뜻 없는 1회용 값만 넣어 주세요.

## 뷰티웰 쪽 동작

- 회원이 뷰티웰에서 「웰리케어」를 누르면 `https://cjb-server.vercel.app/go/wellycare` 로 갑니다.
- 뷰티웰 서버가 B-1을 호출해서 받은 `url` 로 회원을 보냅니다.
- 웰리케어 API가 아직 없거나 실패하면 웰리케어 첫 화면으로 보냅니다. (그쪽에서 직접 로그인)

## 웰리케어가 알려줄 것

| 항목 | 뷰티웰 설정 이름 |
|---|---|
| B-1 API 주소 | `WELLYCARE_TICKET_URL` |
| 웰리케어 첫 화면 주소 (다르면) | `WELLYCARE_APP_URL` (기본 `https://salon.wellycare.kr/`) |

비밀키는 A와 같은 값(`WELLYCARE_SSO_SECRET`)을 양쪽이 같이 씁니다.
